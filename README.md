# Jayesh Jadhav – Research Portfolio (fixed standalone build)

This version is a single self-contained `index.html` file. It has no font, CSS, JavaScript or image dependency, so it works when opened locally and on GitHub Pages.

## Test locally

Open `index.html` directly in Chrome, Firefox, Edge or Safari.

## Publish on GitHub Pages

1. Create a public GitHub repository.
2. Upload `index.html` directly to the repository root (not inside another folder).
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.

## Add your photograph

The current image is a built-in placeholder. For a quick replacement, edit the `<img>` element in the hero section and use your image filename. Place the image in the repository root or create an `assets` folder and update the path accordingly.
